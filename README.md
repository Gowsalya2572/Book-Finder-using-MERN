Book Finder Web Application

A full-stack book search application built using React (Vite) + Node.js/Express + Zustand.
Users can search books, view details, and add them to favorites.

Tech Stack

| Layer      | Technology            |
| ---------- | --------------------- |
| Frontend   | React (Vite), Zustand |
| Backend    | Node.js, Express      |
| Deployment | Vercel                |
| API        | REST API              |
